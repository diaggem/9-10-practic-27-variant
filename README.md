# Вариант 27 — Океанические впадины

## Условие задачи

Создать программу для работы с данными об океанических впадинах. Для каждой впадины хранится:
- название
- глубина
- океан
- тип (разломная, хребет, желоб)

Программа должна:
1. Заполнить массив из 20 впадин
2. Посчитать количество впадин глубже 6000 метров
3. Отобрать все впадины типа "желоб" и отсортировать их по убыванию глубины
4. Вывести океаны трёх самых глубоких впадин
5. Изменить данные впадины по её глубине (не по названию)
6. Попросить пользователя ввести океан и вывести все впадины в этом океане

## Что делает программа

1. Показывает количество впадин глубже 6000 м
2. Выводит список всех желобов (впадины типа "желоб"), отсортированный от самой глубокой к самой мелкой
3. Показывает океаны трёх самых глубоких впадин
4. Меняет данные у впадины с глубиной 8428 метров (можно изменить в коде)
5. Просит ввести океан (Тихий, Атлантический или Индийский) и выводит все впадины в нём (Сделано через ввод номера океана).
